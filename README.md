# Money Tracker — учёт личных расходов

Небольшой REST API на FastAPI для учёта личных расходов: добавление трат,
просмотр списка с фильтром по категории, удаление и статистика по категориям.

Подходит любому, кто хочет вести простой учёт трат через API или использовать
сервис как основу для своего приложения.

## Возможности

- `GET /` — веб-интерфейс (форма добавления трат, список, статистика)
- `GET /api` — информация о приложении
- `GET /health` — проверка работоспособности
- `GET /version` — версия приложения
- `POST /expenses` — добавить трату (описание, сумма, категория, дата)
- `GET /expenses` — список трат, фильтр по категории (`?category=Еда`)
- `GET /expenses/{id}` — трата по идентификатору
- `DELETE /expenses/{id}` — удалить трату
- `GET /expenses/summary/by-category` — сумма и количество трат по категориям

## Установка и запуск

1. Создайте виртуальное окружение и установите зависимости:

```bash
python -m venv .venv
.venv\Scripts\activate        # Windows
# source .venv/bin/activate   # Linux/macOS
pip install -r requirements.txt
```

2. (Необязательно) Создайте файл `.env` на основе `.env.example`.

3. Запустите приложение:

```bash
python -m uvicorn app_final:app --host 0.0.0.0 --port 8000
```

Запуск без `--reload` — обычный рабочий режим. Веб-интерфейс: http://localhost:8000/
Интерактивная документация: http://localhost:8000/docs

## Тесты

```bash
pip install -r requirements-dev.txt
python -m pytest -v
```

## Переменные окружения

| Переменная | По умолчанию | Описание |
| :--- | :--- | :--- |
| `APP_NAME` | `Expense Tracker` | Название приложения |
| `APP_VERSION` | `1.0.0` | Версия приложения |
| `DEFAULT_CURRENCY` | `RUB` | Валюта по умолчанию |
| `MAX_EXPENSE_AMOUNT` | `1000000` | Максимальная сумма одной траты |

## Проверка и диагностика

- Проверка работоспособности: `curl http://localhost:8000/health` — ожидается `{"status": "ok"}`.
- Версия: `curl http://localhost:8000/version`.
- Логи: события (запуск, каждый запрос, добавление/удаление трат, статистика)
  выводятся в stdout в формате `время уровень имя сообщение`. Если сервис не
  запускается, смотрите текст ошибки в консоли; если `/health` не отвечает —
  проверьте, что процесс запущен и порт 8000 свободен.
